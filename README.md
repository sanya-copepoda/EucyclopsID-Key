# EucyclopsID: Interactive Key

Интерактивный многовходовый (поликлавишный) определитель циклопов рода *Eucyclops* на основе базы микропрепаратов А. А. Новикова (Казанский федеральный университет).

## Деплой на Render.com (бесплатный Static Site)

Приложение является полностью автономным клиентским веб-приложением (React + TypeScript + Vite). Вся база из 182 особей, 32 видов, 68 признаков с расшифровками, иллюстрация препарирования и векторная анатомическая схема уже встроены в проект.

### Способ 1: Через GitHub + Render Static Site (Рекомендуется, 100% бесплатно и без «засыпания»)
1. В верхнем меню Google AI Studio нажмите **Download App (Скачать ZIP-архив)** или экспортируйте код в свой репозиторий на **GitHub**.
2. Если вы скачали ZIP-архив, распакуйте его и загрузите файлы в новый репозиторий на [GitHub](https://github.com/new).
3. Перейдите в панель [Render.com Dashboard](https://dashboard.render.com/) → нажмите **New +** → выберите **Static Site** (Статический сайт — он полностью бесплатный навсегда и не уходит в спящий режим).
4. Подключите ваш GitHub-репозиторий и укажите настройки:
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
5. Нажмите **Create Static Site**. Через ~1 минуту определитель будет доступен по вашей постоянной ссылке `https://...onrender.com`.

### Способ 2: Автоматический деплой через `render.yaml` (Blueprint)
В корень проекта уже добавлен файл `render.yaml`. На Render.com можно выбрать **New +** → **Blueprint** и указать ваш репозиторий — все настройки (`npm install && npm run build`, папка `./dist`) применятся автоматически.

### Примечание по картам в профиле вида после выгрузки на Render.com
- Если при деплое на Render.com вы **не указываете** переменную окружения `VITE_GOOGLE_MAPS_API_KEY`, приложение автоматически переключается на встроенную бесплатную карту **OpenStreetMap**, которая работает вообще без API-ключей и без лимитов.
- Если вы захотите использовать подложку Google Maps на своём домене, достаточно добавить переменную `VITE_GOOGLE_MAPS_API_KEY` в разделе *Environment* на Render.com.

## Локальный запуск на компьютере

```bash
npm install
npm run dev
```
Сборка для продакшена:
```bash
npm run build
```
