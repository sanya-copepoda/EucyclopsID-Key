# EucyclopsID: Interactive Key

Интерактивный многовходовый (поликлавишный) определитель циклопов рода *Eucyclops* на основе базы микропрепаратов А. А. Новикова (Казанский федеральный университет).

## Безопасность и отсутствие API-ключей
Приложение является **на 100% автономным клиентским сайтом** (React + TypeScript + Vite + Leaflet/OpenStreetMap):
- В коде и репозитории **нет ни одного ключа Google API** (`GEMINI_API_KEY`, `GOOGLE_MAPS_API_KEY` и т.д.) и **нет платных SDK**.
- Все расчёты (байесовская модель малых выборок, разделительная сила признаков, количественное морфологическое сходство $\Delta\sigma$) выполняются локально в браузере пользователя по встроенной матрице из 182 особей.
- Карта мест сбора работает через бесплатный **OpenStreetMap (Leaflet)** без ключей и лимитов.

## Деплой на GitHub Pages (Открывается в России без VPN, 100% бесплатно)

Проект уже полностью настроен для работы на **GitHub Pages**:
- В `vite.config.ts` прописан относительный базовый путь `base: './'`, поэтому сайт корректно работает по любому адресу вида `https://<ваш-логин>.github.io/<имя-репозитория>/`.
- В папку `.github/workflows/deploy.yml` добавлен готовый сценарий **GitHub Actions** для автоматической сборки и публикации.

### Пошаговая инструкция (занимает 2 минуты):
1. Нажмите в верхнем меню AI Studio кнопку **Export to GitHub** (или **Download App / Скачать ZIP** и загрузите распакованные файлы в новый репозиторий на [GitHub](https://github.com/new)).
   *Примечание: при выгрузке убедитесь, что скрытая папка `.github/workflows/deploy.yml` тоже попала в репозиторий (при прямом экспорте в GitHub она переносится автоматически).*
2. Откройте ваш репозиторий на GitHub и перейдите во вкладку **Settings** (Настройки) → в левом меню выберите **Pages**.
3. В разделе **Build and deployment** в выпадающем списке **Source** выберите:
   👉 **`GitHub Actions`** (вместо *Deploy from a branch*).
4. Перейдите во вкладку **Actions** в верхнем меню репозитория:
   - Если сборка `Deploy to GitHub Pages` ещё не запустилась сама, нажмите на неё слева и нажмите кнопку **Run workflow**.
5. Через ~1 минуту сборка завершится зелёной галочкой, и ваш определитель будет опубликован по постоянной ссылке:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
